Pipeline
1. QC ก่อน เพื่อรู้ว่าข้อมูลมีปัญหาอะไร ก่อนตัดสินใจ trim ซึ่งไม่มีปัญหา
2. Trim ตัด adapter + low-quality bases ออก reads จาก 38.7M → 26.6M
3. qc อีกรอบ ซึ่งไม่มีปัญหา
